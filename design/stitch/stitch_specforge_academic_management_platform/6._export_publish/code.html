1. Course Outcomes (CO) & Taxonomy Levels

Aligned to Revised Bloom's Taxonomy
CO ID Outcome Statement Bloom's Level Weightage
CO1 Analyze asymptotic performance and resource bounds of iterative and recursive algorithms. L4: Analyze 15%
CO2 Apply linear data structures (stacks, queues, deques) to real-world memory buffer problems. L3: Apply 20%
CO3 Implement balanced search trees (AVL, Red-Black) and multi-way trees for dictionary workloads. L3: Apply 25%
CO4 Evaluate graph representations, shortest path traversals, and minimum spanning forest heuristics. L5: Evaluate 20%
CO5 Design composite algorithmic schemes combining dynamic programming and divide-and-conquer paradigms. L6: Create 20%

2. Modular Syllabus Breakdown

Module I • 8 Lecture Hours Complexity & Linear Structures

Asymptotic notation, amortized analysis, linked structures, skip lists, circular buffers.

Module II • 10 Lecture Hours Hierarchical Indexing & Trees

Binary search trees, AVL rotations, B-Trees, prefix tries, binary heaps, Fibonacci heaps.

Module III • 12 Lecture Hours Graphs & Dynamic Optimization

Dijkstra, Bellman-Ford, Kruskal, topological order, memoization, knapsack matrix formulations.

3. Recommended References & Textbooks
  • Cormen, T. H., Leiserson, C. E., Rivest, R. L., & Stein, C. (2022). Introduction to Algorithms (4th ed.). MIT Press.
  • Sedgewick, R., & Wayne, K. (2011). Algorithms (4th ed.). Addison-Wesley Professional.
  • Kleinberg, J., & Tardos, É. (2006). Algorithm Design. Pearson Education.
